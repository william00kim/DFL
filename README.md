# DFL
Docker for LLM server

## 프로젝트 개요
본 프로젝트에서는 한림대학교 정보과학대학 학생들을 위한 LLM 서버를 구축하였습니다. Ollama를 활용하여 오픈소스 LLM 모델을 로컬 서버 환경에 배포하였으며, 모든 모델을 Docker 기반 컨테이너로 운영하여 보안성과 가용성을 향상시켰습니다. 이를 통해 안정적이고 확장 가능한 AI 서비스 환경을 제공하였습니다.
